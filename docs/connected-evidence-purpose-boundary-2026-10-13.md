# Purpose prose and detailed capability evidence

The outline contract is now `operation-outline-2`. Its release policy keeps quantities, bounds, units and stopping-work claims out of purpose prose. These claims are retained as withheld audit data rather than displayed as accepted purpose explanations. A valid operation selection survives even when all purpose claims are withheld.

This is a conservative contract restriction, not semantic verification. It deliberately withholds some correct statements, including broad references to abort handling or numeric identifiers. It can still miss paraphrases. Remaining purpose prose and model questions are unverified; neither may be promoted into production knowledge automatically.

The TypeScript operation extractor now includes:

- Numeric comparison branches with direct throw/return consequences. The transport's actual integer check and comparisons against `1` and `600000` are retained literally. No accepted interval or time-unit conversion is generated by the extractor. Compound arithmetic bounds and other guard forms may be outside this extraction subset.
- Function-valued properties named `isCancelled`, retaining the exact callback source and explicitly stating that exposing a callback does not prove callers invoke it or work stops.
- Direct property calls named `abort`, `cancelTask`, `interrupt` or `terminate`, with lexical conditions. These are named call sites, not proof of effective interruption or receiver identity.

Numeric guards and cancellation probes receive reserved priority ahead of ordinary event records inside the existing bounded packet. Omission counts remain explicit. The readable report displays collector qualifications alongside original source. There is no model-generated conversion of milliseconds to seconds in the observation cards.

## Regression and review

`evidenceOutline.test.js` includes the exact saved incorrect timeout/capability claims, alternate numeric wording, direct-call conditions, real transport comparison spans and the real TaskManager callback. Tests verify that withholding prose leaves selected source observations intact. Existing scheduler/cache, source-version and full offline tests remain applicable.

`node backend/scripts/auditConnectedPurpose.js` replays the preserved October 13 outline answers using their original packet and evidence IDs; it writes `purpose-boundary-replay.json` without making a model request. It does not pretend old answers used the newly expanded context.

The live evaluation command remains:

```powershell
node backend/scripts/evaluateConnectedEvidence.js --live --profile=outline
```

The isolated `last-review.json` and `last-review.md` distinguish collector observations from retained purpose, withheld claims and model questions. Full offline results are in `offline-tests-purpose-boundary-2026-10-13.log` in the same test store. No production background learning or global model settings are changed.
